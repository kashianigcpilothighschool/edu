# মার্কস এন্ট্রি প্যানেল (Google Apps Script)

স্কুলের রেজাল্ট/মার্কস এন্ট্রির জন্য একটি Google Apps Script ওয়েব অ্যাপ —
লগইন + OTP যাচাই + রোল-ভিত্তিক ক্লাস অ্যাক্সেস সহ।

## 📁 ফাইল কাঠামো

```
Code.gs               → মূল সার্ভার-সাইড লজিক (লগইন, OTP, মার্কস সাবমিট ইত্যাদি)
Config.example.gs      → গোপন তথ্যের টেমপ্লেট (আসল sheet ID/OTP এখানে নেই)
Config.gs              → 🔒 আপনার আসল sheet ID ও OTP (এই ফাইলটি .gitignore-এ, GitHub-এ যাবে না)
Login.html             → লগইন/সাইনআপ/পাসওয়ার্ড-রিসেট UI
MarksInput.html         → মার্কস এন্ট্রি ড্যাশবোর্ড UI
appsscript.json        → Apps Script প্রজেক্ট ম্যানিফেস্ট
.gitignore             → কোন ফাইলগুলো গিটে যাবে না তার তালিকা
```

## 🚀 GitHub-এ পুশ করার আগে যা করতে হবে

এই কোডে আগে সরাসরি লেখা ছিল:
- Users শীটের Spreadsheet ID
- প্রতিটি ক্লাস/শাখার Spreadsheet ID
- `MASTER_OTP` (সব ইউজারের জন্য কাজ করা বাইপাস কোড)

এই তথ্যগুলো এখন **Config.gs** নামের আলাদা ফাইলে রাখা হয়, যেটি `.gitignore`-এর
কারণে কখনো GitHub-এ যাবে না। `Code.gs`-এর লজিক/আচরণ অপরিবর্তিত আছে — শুধু
মানগুলো `CONFIG.xxx` থেকে আসছে।

**সেটআপ করতে:**

1. `Config.example.gs` ফাইলটি কপি করে `Config.gs` নামে সেভ করুন (একই ফোল্ডারে)
2. `Config.gs`-এ আপনার প্রকৃত Spreadsheet ID ও OTP বসান
3. `clasp push` করলে `Config.gs` সহ সব ফাইল আপনার Apps Script প্রজেক্টে যাবে
   (কিন্তু GitHub-এ শুধু `Config.example.gs` দেখা যাবে, `Config.gs` না)

## 🔧 clasp দিয়ে ডেপ্লয় করা

```bash
npm install -g @google/clasp
clasp login
clasp clone <YOUR_SCRIPT_ID>   # অথবা বিদ্যমান প্রজেক্টে clasp push
clasp push
clasp deploy
```

`.clasp.json` ফাইলটিও `.gitignore`-এ রাখা আছে যাতে আপনার Script ID সরাসরি
GitHub-এ প্রকাশ না হয় (চাইলে এটি রিপোতে রাখতে পারেন, এটি সংবেদনশীল নয় এমন
মনে করলে .gitignore থেকে বাদ দিন)।

## ⚠️ নিরাপত্তা সংক্রান্ত নোট (কোড পরিবর্তন করা হয়নি, শুধু মনে করিয়ে দেওয়া হলো)

- **MASTER_OTP**: এই কোড এখনো `Code.gs`-এ আছে এবং সব ইউজারের জন্য কাজ করে।
  এটি production-এ চালু রাখলে যে কেউ সঠিক ইমেইল/পাসওয়ার্ড জানলে এই কোড দিয়ে
  লগইন করতে পারবে। প্রয়োজন না হলে এই ফিচারটি বন্ধ/অপসারণ করার কথা বিবেচনা করুন।
- **MarksInput.html**-এর "Others/Editor/Transcript" বাটনগুলোতে একটি লাইভ
  `script.google.com/macros/...` ডিপ্লয়মেন্ট URL এবং `kashiani1.pages.dev`
  ডোমেইন হার্ডকোড করা আছে। এগুলো গোপন তথ্য নয়, তবে রিপো পাবলিক করার আগে
  আপনি চান কিনা যাচাই করে নিন।
- স্কুলের নাম (কাশিয়ানী জি.সি. পাইলট উচ্চ বিদ্যালয়) UI-তে হার্ডকোড করা আছে;
  এটি একটি প্রদর্শনী স্ট্রিং, প্রয়োজনে নিজের মতো বদলে নিন।

## ✨ ফিচারসমূহ (অপরিবর্তিত)

- ইমেইল + পাসওয়ার্ড + OTP ভিত্তিক দুই-ধাপের লগইন
- সাইন-আপ + অ্যাডমিন অনুমোদন (pending → active/blocked)
- পাসওয়ার্ড রিসেট (OTP-ভিত্তিক)
- ক্লাস/শাখা অনুযায়ী রোল-ভিত্তিক অ্যাক্সেস কন্ট্রোল
- অর্ধবার্ষিক/বার্ষিক পরীক্ষার জন্য আলাদা কলাম অফসেট
- CQ/MCQ মার্কস এন্ট্রি, পেজিনেশন ও সার্চ সহ
